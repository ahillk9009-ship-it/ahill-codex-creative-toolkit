# 검증 범위

이 문서는 공유본 코드의 재현 가능한 검사와 Adobe 앱에서 필요한 검사를 구분합니다.

## 공유본 작성 시 확인한 결과

2026-09-09, Windows의 임시 작업 폴더에서 확인했습니다.

| 검사 | 결과 |
|---|---|
| Python 단위·동작 검사 | 23개 통과 |
| Node 공유 브리지·패널 호환 검사 | 16개 통과 |
| 실제 MCP 프로토콜 초기화와 도구 목록 | 모의 UXP 허브를 연결한 실행기로 통과 |
| 한국어 의미 검색 | 소켓 연결 차단 상태에서 검색·프로젝트 격리·수정·재색인 통과 |
| Premiere 패치 | npm에서 새로 설치한 1.14.5 원본 사본에 3개 파일 적용·재적용 확인 |
| Photoshop 패치 | 2.0.1 배포 원본 사본에 4개 파일 적용·재적용 확인 |
| Windows PowerShell 설치 | 공백이 있는 임시 경로에서 스킬 4개 설치 확인 |
| 스킬 형식 | OpenAI skill-creator 검증기로 4개 통과 |
| 배포 구성 | 문서 내부 링크, 공개 파일 목록, 기본 유출 패턴 검사 통과 |

의미 검색 검사는 기존에 준비된 의존성·모델 캐시를 재사용했습니다. 새 PC의 모델 다운로드와 모든 선택형 외부 도구를 처음부터 설치하는 과정까지 재검증한 것은 아닙니다. Adobe 앱을 열거나 원래 제작 환경의 패널·Codex 설정을 변경하지 않았습니다.

## 자동 검사

```powershell
python -m unittest discover -s tests -v
npm ci --prefix adobe/premiere --ignore-scripts --no-audit --no-fund
npm test --prefix adobe/premiere
python toolkit.py check-release
```

Python 검사는 임시 폴더에 설치하여 재설치, 한글·공백 경로, 충돌 시 기존 파일 보존, TOML 주석·기존 값 보존, 백업, 패치 해시·경로 검사, 기억 수정 이력·프로젝트 격리·동시 저장, ZIP 공개 파일 목록을 확인합니다.

Node 검사는 실제 Adobe 앱 대신 가짜 패널과 로컬 임시 포트를 사용합니다. 여러 클라이언트 연결, 인증 실패 거부, 명령 직렬화, 연결 복구, 중단한 명령의 재실행 방지, UXP 암호 API 호환, 폴더 취소 및 연결 정보 복원을 검사합니다. 실제 패널의 전체 API를 대신 검증하지는 않습니다.

선택형 의미 검색은 준비된 가상환경에서 다음으로 확인합니다.

```powershell
<semantic-python> tests/semantic_smoke.py
```

메모리 테스트는 임시 DB를 사용하며 원래의 개인 기억을 읽거나 수정하지 않습니다. 의미 검색 검사는 모델 캐시를 미리 준비해야 합니다.

## 새 PC에서 필요한 수동 검사

- 새 Codex 세션에서 해당 스킬과 MCP 도구가 보이는지.
- Premiere/Photoshop/AE에서 실제 로드한 패널 경로와 버전이 맞는지.
- 패널 연결 이후 실제 호스트·프로젝트·시퀀스·레이어 상태를 조회할 수 있는지.
- 테스트용 합성 프로젝트로 편집·저장·미리보기·출력이 되는지.
- 앱을 재시작한 뒤 페어링과 재접속이 유지되는지.
- 결과 영상·이미지를 직접 확인하고 필요한 오디오를 청취했는지.

기존 제작 PC에서 성공했던 기록만으로 다른 사용자의 환경도 검증됐다고 표시하지 않습니다. CI 워크플로를 제공하지만 GitHub에 올리기 전에는 원격 CI가 실행된 것이 아닙니다.
